ZKP 零知识隐私认证Sigma Protocol + Fiat–Shamir Transform7Sigma 协议流程（知识证明骨架）1Commit证明者生成随机承诺commitment = H(witness, r)→2Challenge验证者发送随机挑战challenge ← {0,1}²⁵⁶→3Response证明者计算响应response = f(witness, challenge)Fiat–Shamir 变换 → 非交互式 ZKP挑战值由证明者自行计算：challenge = Hash(commitment ‖ public_input ‖ message)证明格式：π = (commitment, response, challenge_digest)验证者重算挑战并校验：Commit(public_input, response) = commitment + challenge · public_input优势：无需交互 → 适合 IoV/V2X 高延迟不可靠信道；每次认证生成全新证明，不可链接

--- Slide 8 ---
PLS 物理层双因子认证CSI Fingerprint as Second Factor8CSI 信道指纹原理CSI (Channel State Information)：描述无线信道多径传播特性空间唯一性：不同位置的信道特征高度不相关时变性：CSI 随时间变化，增加不可预测性本实现：Rayleigh 多径模型仿真 CSI 幅度特征默认维度：64 子载波 × 8 多径匹配算法：皮尔逊相关系数 ρ认证判定：ρ ≥ γ (默认 γ = 0.85)实际部署：可替换为 802.11p / 5G NR CSI 采集数学模型ρ = Cov(Φ_V, Φ_R) / (σ_V · σ_R) ≥ γΦ_V: OBU 上报 CSI    Φ_R: RSU 测量 CSIγ: 认证阈值 (默认 0.85)防御场景证书窃取 + 远程冒充：  异地 CSI 不匹配 → 拒绝中继攻击：  中继改变信道特征 → 降分物理邻近攻击：  不同位置 CSI 高度不相关
