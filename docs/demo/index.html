一、研究背景

产业需求

V2X 协同感知与安全预警依赖可信身份。OBU 与 RSU 在开放无线环境中交换敏感数据，认证失败将导致伪造、追踪与恶意接入。

  • 隐私不足 — XOR/假名仍可能关联轨迹
  • 盗证异地用 — 纯密码学无法证明「车在现场」

三、本项目创新

架构创新

首次在可复现 IoV 原型中将 PQC + 格 ZKP + PLS + 会话帧 四层串联，RSU 短路验证 ZKP→PLS→PQC。

算法创新

SIS-Σ-NIZK 与 Dilithium 同族，证明 A·s≡t (mod q)；相对 Sigma 骨架，伪造 response 通过率从 100% 降至 0%。

实验创新

七组可复现实验 + 盗证消融（主实验 PLS 开启 0% / 对照 counterfactual 100%）+ V2X 校准 CSI 双模式验证。

工程优化

会话帧摘要签名、CSI float32 压缩、Replay Guard、基线密码学复现（非 sleep 占位）。

四、理论基础

PQC
CRYSTALS-Dilithium / ML-DSA（FIPS 204）· 格上 SIS 困难问题 · 抗量子签名与完整性
ZKP
SIS-Σ-NIZK · Lyubashevsky 拒绝采样 + Fiat-Shamir · 最小披露「持有合法密钥」
PLS
CSI 信道指纹 · 皮尔逊 ρ + 归一化距离双判据 · 异地盗证 ρ 显著降低
会话
IoVAuthFrame · RSU ID + 时间戳 + nonce · Replay Guard 5s 窗口去重
